# Portfolio pilot methodology

## Scope

The active portfolio contains 16 reviewed public advisory/version families and
8 metadata-only future evaluation candidates. Only the 16 public families are
represented in questions, packets, retrieval, review, grading, and metrics.
The family and its coarsest incident, vendor/product, source-release, template,
and challenge-generator dependencies are the independence and split unit.

The result is evaluated offline and provider-free. It does not estimate model
performance or condition improvement and does not support confirmatory or broad
CTI generalization claims.

## Temporal and provenance rules

Each public case binds a cutoff, exact source state and hash, normalized
document, evidence span, and predicate-specific authority. A claim succeeds
only when the atomic value and supporting evidence pass exact match, span,
cutoff, and authority checks.

Publisher-declared version evidence proves what a named publisher version says
and its declared time. Independently observed historical availability requires
an actual observation or archive by the cutoff; the former is never promoted
to the latter.

## Matched evidence-selection controls

Each of the 16 public families has three packet variants: clean, benign control,
and safe synthetic challenge. Four families each use stale evidence, a lower-
authority contradiction, a safe instruction-like passage, or a plausible
unsupported assertion. Every packet contains more than the retrieval depth of
six documents.

Recall@6 is reported separately for each variant and is 16/16 in all three. It
is a controlled packet and lexical-retrieval contract check. It does not prove
model reasoning, citation faithfulness, realistic attack prevalence, attack
resistance, or general retrieval robustness.

## Human review

The one available human reviewer audited 20 blinded items covering all 16
public families. Four families resurfaced later under opaque identifiers; all
four pairs received the same active verdict. The 4/4 figure is intra-rater
repeatability, not agreement between reviewers and not proof that labels are
correct. Append-only supersession preserves the discovered DD-WRT correction.

## Answerability and future evaluation

All 16 public portfolio cases are answerable. Correct and unnecessary
abstention are therefore not evaluated for this portfolio; historical
Log4Shell plumbing does not increase this denominator.

A later provider experiment, if separately authorized, may be described only
as a bounded descriptive development/validation study. Its model, cases,
conditions, repetitions, failure policy, token estimate, and hard cost cap must
be frozen and approved first. It is not required for the provider-free public
portfolio release.
